How it works
  1. Pick the host and environmentThe instance runs on a Linux host you added before.
  2. Choose how WARs arriveSSH / SFTP uses the host's login; Tomcat Manager uses its own web API and account.
  3. Set the location and file nameEach release is copied to the deployment directory under this name.
  4. Keep the safety checks onBackups make rollback possible; the health check confirms the application started.
  5. Save, then testRun Test connection on the instance page before the first deployment.
