How it works
  1. Enter the server and loginLike a WinSCP session: host, port, user and a password or key.
  2. Test connectionConnects over SSH and opens SFTP. Nothing is changed on the server.
  3. Accept the host keyOnly after comparing it with the fingerprint shown on the server.
  4. SaveThen add the Tomcat instances that run on this host.
Tomcat Manager (HTTP/HTTPS) deployments don't use SSH; set them up on the Tomcat instance instead.
