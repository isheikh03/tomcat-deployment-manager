LINUX HOST · TOMCAT INSTANCES

Find Tomcat instances on host

Scans host and suggests the Tomcat applications that are not added yet. Tick the ones you want: they are saved with the required settings, and you complete the rest later.

How the scan works

  • It only reads files over SFTP with the host's SSH login; no command is run and nothing is changed on the server.
  • It looks at running Tomcat processes (/proc), systemd units named *tomcat*.service, and folders with conf/server.xml below /opt, /usr/share, /var/lib, /usr/local, /srv and /home.
  • For each Tomcat it reads the HTTP port, the deployment folder, the version and the applications (WAR files) deployed there.
  • Places the SSH account may not read are skipped. Anything not found can still be added by hand.
