What happens on upload

  1. Streamed to private storageNever held in memory or served publicly.
  2. SHA-256 computed on the serverThe fingerprint used to verify the file before every deployment.
  3. Checked as a real WARValid ZIP with WEB-INF/, no unsafe paths.
  4. InspectedJava class level and javax/jakarta Servlet API are detected for compatibility checks.
  5. Stored once, read-onlyIdentical files share storage; the bytes can never be changed.
